# SlideSpect

Multi-page front-end prototype for landslide-risk monitoring research.

## Upload
Upload the contents of this folder to the repository root. Vercel needs no build command; use the repository root as the Root Directory.

## Included
Home, Monitoring, Risk Analysis, Dashboard, Alerts and About pages; Leaflet maps; live Open-Meteo weather/soil-moisture/elevation requests; responsive navigation.

## Data foundations
NASA GPM/IMERG: https://gpm.nasa.gov/data/imerg
Copernicus DEM: https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Data/DEM.html
ESA WorldCover: https://esa-worldcover.org/en/data-access
GSI Bhusanket: https://bhusanket.gsi.gov.in/
Open-Meteo: https://open-meteo.com/
OpenStreetMap: https://www.openstreetmap.org/

## Important
The current screening index is a UI prototype, not a trained ML model, official hazard forecast, or emergency warning. It must be replaced by a validated model after the historical labelled dataset is built.
