# SlideSense

Landslide Risk Monitoring & Early Warning System.

## Current version

This is the first front-end prototype.

### Files

- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — future interactivity
- `assets/` — images and icons

## Development idea

Build SlideSense step by step:

1. Front-end interface
2. Interactive dashboard
3. Maps and visualizations
4. Backend/API
5. Live environmental data
6. Machine-learning risk analysis
7. Early-warning system
